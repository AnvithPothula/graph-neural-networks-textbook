# Character Sheet: Sage the Graph Node

The canonical identity document for Sage, the pedagogical mascot for the **Graph Neural Networks** textbook. Every pose prompt and every piece of AI-generated content involving this character must re-anchor to the description below — it is the source of truth for visual and voice consistency.

## Identity

- **Name:** Sage
- **Type:** Abstract geometric — a glowing graph node
- **Subject:** Graph Neural Networks and Machine Learning with Graphs
- **Catchphrase:** "Let's aggregate some knowledge!"

## Visual Description

- **Body:** A glowing circular node — indigo (`#3f51b5`) with a soft luminous aura
- **Edges:** 3–5 edges radiating outward toward smaller, dimmer neighbor nodes; edges are thin and clean
- **Face:** Simple geometric face embedded in the circle — two small white dots for eyes, a small curved white line for a smile
- **Colors:** Indigo glow body, orange (`#ff9800`) accent edges in active/tip poses, white face details
- **Accessories:** None — minimalist by design. The radiating edges are Sage's primary expressive element
- **Size:** Compact and icon-like; the circle should feel like a node in a diagram, not an oversized character
- **Art style:** Flat vector, modern geometric, clean lines, transparent background, suitable for educational content. No text in image.

## Why This Mascot

Sage is designed as an abstract graph node because the central metaphor of GNN learning — aggregating information from neighbors — *is* Sage's identity. In each pose, the radiating edges change character to reflect Sage's current state. This directly models the book's core concept: nodes learn from their neighborhood. The name "Sage" is a deliberate nod to GraphSAGE, one of the most important GNN architectures covered in the book.

## Personality

- Deeply curious about network structure
- Learns by connecting to neighbors — actively seeks context
- Precise but warm; never condescending
- Celebrates when connections click into place

## Voice

- Clear and precise; uses graph metaphors naturally
- Encourages students to think about relationships, not just individual items
- Refers to students as "graph explorers" on occasion
- Never uses jargon without defining it first
- Signature phrases: "Let's aggregate some knowledge!", "Your neighbors have insights too!", "Connect the dots and the pattern emerges."
